Puppeteer training, for tracking world model on Amarel cluster (RHEL 9.6). Also tested setup phase (not training) on iLab on Ubuntu 22.04

-installed miniforge instead of conda
-installed environment, had to downgrade setuptools and wheel for gym
edit environment.yaml to request stable release instead of nightly (0.3.1)
pip install "setuptools==65.5.0" "wheel==0.38.4"
pip install gym==0.21.0
sed -i 's/torchrl-nightly==[0-9\.]*/torchrl==0.3.1/g' docker/environment.yaml
sed -i 's/tensordict-nightly==[0-9\.]*/tensordict==0.3.1/g' docker/environment.yaml
